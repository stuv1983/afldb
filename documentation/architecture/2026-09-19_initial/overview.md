## 4. API surface

`.phaneslight/registry/api-contract.json` is a dedicated slice, because for a project that exposes
a network surface the *public contract* is what must not drift silently — internal exported symbols
are a different question. As at 2026-09-19 it holds **19 HTTP route handlers** and **123 server
actions** (142 entries).

There is **no OpenAPI document and no GraphQL SDL in this repository** — verified by extension
search across the tracked set on 2026-09-19 — so the contract is extracted from the route and
action definitions themselves. Note the routes are not confined to `src/app/api`: admin routes
(`/admin/content/asset/[...path]`, `/admin/nl-search/export`) and `/beta/verify` are equally
network-reachable and are included.
